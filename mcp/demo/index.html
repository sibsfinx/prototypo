Two families from the local MCP: a display cut of Antique Gothic (Poster Display) and a text cut of Spectral (Reader Text). Pairing follows the same split Hoefler&Co makes between Multipurpose/headline faces and ScreenSmart text, and that CSTM makes between Kazimir and Kazimir Text: wider, higher contrast, and baked alternates for the poster; lower contrast, more spacing, and default forms for reading.

Ligatures & features

Both columns use the same string. The left asks CSS for liga, dlig, calt, ss01, salt. The right turns them off. If this app exported GSUB, “office”, “affiliate”, and “ffi” would change. They will not: the OTF writer emits CFF outlines and cmap only. There are no fi/fl ligature glyphs in the templates.

Alternates do exist, but they are selected in the editor (altList) and baked into cmap before export. Poster Display used a_alt, t_alt, y_alt, one_alt, five_alt, Q_alt where the Antique Gothic source had them. That is not an OpenType stylistic set; CSS cannot toggle it.

What serious foundries ship that we do not

Read against typography.com (Gotham, Ringside, Chronicle, Whitney ScreenSmart), CSTM Fonts, and Kazimir Text on type.today:

  • Optical size as a product, not a slider guess. H&Co ScreenSmart vs Multipurpose; CSTM Kazimir vs Kazimir Text. We faked it with thickness/contrast/spacing on one Regular.
  • A family tree. Weights, widths, italics with consistent intervals. We export one Regular per experiment.
  • OpenType GSUB/GPOS. Standard + discretionary ligatures, stylistic sets, case-sensitive punctuation, kerning. Our OTTO files have none of this.
  • Figure sets. Lining/oldstyle, tabular/proportional, slashed zero, fractions, superiors. One set of lining figures, no feature tags.
  • Small caps. Prototypo has small-cap sliders; they are not a smcp feature.
  • Language coverage. CSTM’s job is often Cyrillic (and Georgian). Our templates are Latin, incomplete accents, no Cyrillic.
  • Variable fonts. Normalidad / Xprmntl 03 / Kazimir VF. We interpolate params in the editor, then flatten to static CFF.
  • Web packaging. WOFF2, subsetting by language, licensed CSS kits. We drop a raw .otf into @font-face.
