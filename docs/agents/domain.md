# Domain Docs

Single-context layout.

## Before exploring, read these

- `CONTEXT.md` at the repo root
- `docs/adr/` for decisions that touch the area
- `openspec/specs/` and `openspec/changes/` for current behavior and in-flight deltas

If a listed file is missing, proceed silently. `/domain-modeling` creates glossary and ADRs when terms actually resolve.

## File structure

```
/
├── CONTEXT.md
├── AGENTS.md
├── docs/adr/
├── docs/agents/

└── app/
```

## Vocabulary

Use terms as defined in `CONTEXT.md`. Do not invent synonyms the glossary avoids.
